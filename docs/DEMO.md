# SIH demo guide
1. Login → Continue as Collector. 2. SELL E-WASTE: photo, PCB, 8 kg, classify,
estimate (~₹1,440). 3. Create lot. 4. Price board → history + Listen (TTS).
5. Find recycler → REQUEST QUOTE on the new lot. 6. Logout → Continue as Recycler.
7. Incoming lot → SUBMIT QUOTE. 8. Handover tab → CONFIRM PICKUP → CONFIRM
HANDOVER → MARK PAID. 9. Logout → Collector → My Lots: accept was already done;
see receipt + QR + traceability; earnings updated. 10. Continue as Admin →
dashboard + analytics reflect the new transaction. Reset via Admin → System.

# Unit Economics

## Overview

K-SETU includes an editable unit-economics section under **Admin → Insights**. It provides a prototype-level view of the potential economics of an e-waste collection transaction and the platform.

**Important:** All figures currently shown are assumption/demo data. They are not verified market rates, audited financial results, or findings from field research.

## Purpose

The unit-economics view is intended to help the team explore how transaction value, operating expenses, platform revenue, and collector benefits may relate to one another.

It can support:

* Early-stage business-model exploration.
* Comparison of different illustrative cost and revenue assumptions.
* Discussion of potential platform sustainability.
* Preparation for future validation with real operational data.

## Editable metrics

The Admin → Insights section includes the following fields:

| Metric                    | Description                                                                                    |
| ------------------------- | ---------------------------------------------------------------------------------------------- |
| Average transaction value | Illustrative average monetary value of an e-waste transaction.                                 |
| Formal-channel value      | Assumed value attributed to processing or selling material through a formal recycling channel. |
| Operating cost            | Estimated cost of operating the platform and supporting its services.                          |
| Transaction cost          | Estimated cost associated with processing or facilitating a transaction.                       |
| Platform revenue          | Assumed revenue earned by K-SETU for facilitating transactions or providing services.          |
| Collector benefit         | Estimated financial benefit received by a collector through the platform workflow.             |

The precise definitions, calculation methods, and units should be checked against the current application implementation before using the values in financial projections.

## Interpreting the figures

Unit economics can help assess whether a transaction model may be financially sustainable. For example, a future validated model could compare:

* The value generated by a transaction.
* The costs incurred to facilitate and support it.
* The revenue retained by the platform.
* The benefit received by the collector.

These relationships depend on actual material prices, transaction volumes, logistics, operating costs, and the platform's revenue model. Demo values should be treated only as inputs for exploration.

## Assumptions and limitations

* Current figures are **ASSUMPTION / DEMO DATA**, not measured results.
* The values have not been established through verified field research.
* Actual costs and benefits may vary by material type, location, quantity, recycler, and logistics arrangement.
* The displayed values should not be presented as proven profitability, market validation, or guaranteed collector earnings.
* Any calculations or charts based on these values inherit the limitations of the underlying assumptions.

## Future validation

Before using unit economics for business decisions, the team should:

1. Collect real transaction and operating-cost data.
2. Validate material prices and formal-channel values with relevant recyclers and aggregators.
3. Document the source, date, and method for each assumption.
4. Measure collector benefits using actual completed transactions.
5. Revisit the calculations as transaction volume and operating conditions change.

## Responsible presentation

When presenting K-SETU to mentors, judges, or potential partners, clearly label these figures as illustrative assumptions. Do not describe them as verified financial performance or field-research findings until supporting evidence is available.
